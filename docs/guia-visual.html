5. Layout e celular

  • Alinhamento: posts e sidebar partem do mesmo topo e usam o mesmo espaçamento, definido por --sp-gap (20px). Para mudar o respiro do site, altere só essa variável.
  • Colunas: posts flexíveis + sidebar de 300px (main.column.right.width). Largura máxima do site: 1020px.
  • Celular (até 860px): a sidebar passa para baixo dos posts, a data do post vira etiqueta acima do título e o rodapé empilha.
  • Logo no cabeçalho: é uma imagem real (img.sp-logo), com largura 100% e altura automática; abaixo de 480px fica limitada a 340px e centralizada. Para trocar a imagem, use Layout › Cabeçalho › Editar. Não volte a usar a opção de imagem como fundo do texto com altura fixa.
  • Menu no celular (até 860px): as pílulas viram um menu suspenso. O botão "☰ Menu" usa Rosa 400 com texto #444; a lista abre em cartão branco com borda rosa e hover azul. Todos os itens devem ficar no mesmo gadget HTML.
  • Telas pequenas (até 480px): títulos e botões menores, paginação sem os botões "primeira" e "última".
  • Ajuste do Blogger: Tema › ⚙ › Tema para dispositivos móveis › "Não. Mostrar o modelo para computador em dispositivos móveis". Sem isso, o Blogger pode servir o modelo simplificado.
  • Regra para novos widgets: não use larguras fixas em pixels. Use max-width:100% e teste abaixo de 400px.

6. Como editar

  • Trocar cores: Tema › Editar HTML › procure :root e altere as variáveis --sp-*. Nunca digite um hexadecimal solto nas regras.
  • Novo componente: use só os tokens. Fundo claro: borda Rosa 400 e texto Azul 700. Fundo escuro de destaque: Rosa 700 ou Azul 700 com texto branco.
  • Paginação: no script page-navi, o valor perPage precisa ser igual a Configurações › Postagens › "Número de postagens na página principal". O padrão é 5.
  • Menu: edite o HTML do gadget da área superior. Cada item é <div class="menuattitude"><a href="...">. Use sempre links https://sakuraplanetscc.blogspot.com/....
  • Imagens: envie pelo próprio Blogger. Não use hotlink de outros sites (Imgur, Photobucket e Dropbox deixaram de funcionar).

7. Evitar

  • Verde, amarelo, roxo, magenta (#fa58f4) e bege. Não fazem parte da identidade.
  • Scripts de terceiros em http:// e jQuery antigo. O navegador bloqueia por conteúdo misto e há falhas de segurança.
  • Comentários CSS com //. Em CSS só vale /* */.
  • font-style: bold, font: century gothic e chaves soltas. Invalidam a regra seguinte.
  • Bloquear o botão direito do mouse no rodapé.
  • Larguras fixas em pixels em widgets e posts: quebram o layout no celular.
  • Esconder gadgets de anúncio com display:none: o AdSense não preenche em espaço sem largura. Recolha com altura zero, como o tema já faz.
  • Gadgets vazios ou com <br> só para criar espaçamento. No celular viram cartões em branco na sidebar. Use CSS (margens e --sp-gap).

Checklist antes de salvar: abra a home, um marcador, um post e a busca; teste uma página numerada; veja no celular.
